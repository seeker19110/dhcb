## Việc đã làm

- **`.claude/hooks/block-pipe-to-shell.sh`** (PreToolUse Bash, exit 2): chặn ba dạng tải mã từ
  mạng rồi chạy thẳng — ống (`curl … | sh`, `… | sudo -E bash -`, `… | python3 -`), thế lệnh
  (`sh -c "$(curl …)"`, `eval "$(curl …)"`), thế tiến trình (`bash <(curl …)`, `source <(…)`,
  `. <(…)`). Bỏ nội dung trong nháy đơn + thân heredoc trước khi so khớp (commit message nhắc tới
  lệnh không bị chặn oan). Cần hook vì luật quyền `Bash(curl * | bash)` không bao giờ khớp
  (Claude Code tách lệnh theo `|`, changelog 0468). Bỏ qua có chủ đích: `ALLOW_PIPE_TO_SHELL=1`.
- **`.claude/hooks/shared-file-reminder.sh`** (PreToolUse Edit/Write/MultiEdit, KHÔNG chặn): lần
  đầu trong phiên sửa một file được ≥ 20 nơi import (đếm bằng `jq` từ `.codemap/graph.json`, ~0,07
  giây) → `additionalContext` nhắc chạy `npm run codemap -- impact <file>`. Bản mềm của GateGuard
  (ECC chặn MỌI file lần đầu — quá nhiều ma sát). Chưa có bản đồ thì im lặng, không tự quét (lần
  quét đầu ~45 giây). Ngưỡng 20 ≈ 42 file ở thời điểm đo.
- **`TRAPS.md` mục 8 — tái phát**: biến thể ký tự định dạng vô hình (zero-width/bidi) do công cụ
  ghi file giải mã escape, ba lần trong đợt 0468; kèm bẫy `grep -P` thiếu locale UTF-8 xanh giả.
  Ghi theo phán quyết "Bổ sung vào mục 8" của `/learn` (không tạo mục trùng), chủ dự án đồng ý.
- **`scripts/claude-hooks.test.ts`**: 13 lệnh phải chặn + 11 lệnh phải cho qua (kể cả
  `curl-config … | bash`, commit message, heredoc) + bypass; hook nhắc chạy trên repo giả trong
  thư mục tạm với `graph.json` giả (CI không có `.codemap/`).
- `.claude/settings.json` đăng ký hai hook; CLAUDE.md mục 8; `PROGRESS.md` (đợt 2: đã xong 4 + 5,
