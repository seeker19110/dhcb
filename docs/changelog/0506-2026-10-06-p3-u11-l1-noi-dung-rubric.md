## Quyết định trong ranh giới đặc tả

- **README nằm trong kho mẫu** (đặc tả: "fixture … cùng benign README"), chấm `headContent` đúng
  nội dung của từng kho → ca ẩn bắt lời giải ghi đè README bằng chữ của kho công khai.
- **Không lấy file tên `__pycache__` làm probe âm:** mẫu `__pycache__` (không gạch chéo) khớp cả
  thư mục lẫn file cùng tên như Git thật — là lời giải đúng, không được bác.
- **Kiểm output `$ git commit`:** `expected` là trường bắt buộc của schema; HEAD chỉ tồn tại khi học
  viên commit, nên chuỗi này không bác lời giải đúng nào mà vẫn cho học viên quên commit thấy lại
  transcript.
